# RELEASE v0.13.2 — Patch: Semgrep + Trivy security scan in CI

**Status:** ready — `make check` green locally; first Security run pending (user)
**Theme:** add the SAST + vulnerability scan cogent already runs, beside the RustSec audit.

## Release notes

### Added
- `.github/workflows/security.yml`, ported from `~/code/cogent`:
  - **Semgrep SAST** (`p/rust`, `p/javascript`, `p/dockerfile`, `p/sql-injection`, `p/secrets`,
    `p/owasp-top-ten`), `--error`, SARIF uploaded to the Security tab. `SEMGREP_APP_TOKEN` is optional.
  - **Trivy** filesystem scan (`Cargo.lock`, Dockerfile, tracker deps): fails on CRITICAL/HIGH, plus a
    SARIF pass for the Security tab.
  - Triggers: push to `main`, PRs, and weekly (Monday 06:00 UTC) so new advisories surface without a commit.
- Cogent's Go/Python Semgrep packs are swapped for the ones that match this repo. All actions are
  SHA-pinned (AC0.10.6a still covers them).

`ci.yml` is unchanged: `cargo audit` + `cargo deny` stay the lockfile gate; this adds source-level SAST.
No code, dependency or version-file changes.
