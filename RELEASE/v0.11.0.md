## Also fixed (found by the first `v0.10.0` tag run on GitHub)

- **Real-browser budget measured the wrong thing in CI.** `init` was `t1 − t0` around the script tag, which includes
  fetching the file: 107 ms on a cold CI runner while long tasks were 0.0 ms. It now measures execution only
  (`responseEnd → init done`: 3 to 14 ms) plus the long-task total; the fetch is reported separately.
- **`release_script` tests failed on CI** (no git committer identity on the runner). The script and tests are
  removed: `make release` is veda's target again (commit, then `make release VERSION=x.y.z`).
- Dependabot removed (its PRs could not take majors and failed CI); updates are manual behind the gate.
- Verified from a clean `git ls-files` checkout on Node 22.23.3: `make check` and `make browser-test` both exit 0.
