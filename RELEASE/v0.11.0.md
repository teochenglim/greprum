# RELEASE v0.11.0 — Dependency upgrades

**Status:** planned
**Theme:** *Take the major versions Dependabot proposed, deliberately, one at a time.*

## Why

Dependabot (now grouped, minor/patch only, monthly) cannot take majors safely: each needs a code change.
Pending majors seen on the first run: axum 0.7→0.8, tower-http 0.5→0.7, sqlx 0.8→0.9, jsonwebtoken 9→11,
esbuild 0.25→0.28, jsdom 26→30, playwright-core 1.55→1.64, and GitHub Action majors (download-artifact 4→8,
setup-buildx 3→4, setup-qemu 3→4, …). Also: sqlx is the only path to `rsa` (ADR 0051); check whether the new
sqlx drops it.

## Order (one commit each, gate between)

1. Rust web stack (axum + tower-http) · 2. database driver (sqlx 0.9 or swap to `mysql_async`) · 3. jsonwebtoken · 4. other crates (`cargo update`)
5. tracker toolchain · 6. Action majors.
