## One-time setup (user)

1. The repo already has `origin` → `ssh://git@github.com/teochenglim/greprum.git`.
2. First tag push creates the package; set **Package settings → Change visibility → Public** if you want
   anonymous `docker pull`, and link the package to the repo (Actions then keep write access).
3. Local manual push (optional): `echo $GITHUB_PAT | docker login ghcr.io -u teochenglim --password-stdin && make docker-build docker-push`.
