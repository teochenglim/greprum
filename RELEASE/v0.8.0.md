# RELEASE v0.8.0 — Jobs wired

**Status:** complete — all ACs green (offline + live DB)
**PRD delta:** §5 Sessions list / first-seen, §6 retention and loss metrics, §7 step 7 (reconcile)
**Theme:** *Retention and the loss estimate work in production, not only in tests* — and the first tag build goes green.

## Why

`first_seen_sql()` and `reconcile::run_once()` exist and are tested, but nothing runs them inside
`greprum serve`. Today `/api/v1/stats/retention` stays empty and `greprum_browser_loss_estimate_ppm`
stays 0 unless an operator runs the SQL by hand.

## Acceptance criteria

| AC | Criterion | Reqs | Tests (cases) |

| AC0.8.1 | A scheduler inside `serve` runs the first-seen insert for every configured site on an interval (`[jobs] first_seen_secs`, default 3600), idempotently | R-J1, R-S5, R-Q8 | (a) tick runs the job once per site with an injected clock and executor (b) interval honoured, no run before due (c) failure is counted and does not stop the loop (d) live: events → tick → `first_seen` rows → retention endpoint non-empty |

| AC0.8.4 | Two gateways running the jobs against one database never duplicate `first_seen` rows | R-J1, R-S5 | (a) live: two concurrent runs ⇒ one row per visitor (b) job metrics: last run timestamp and failure count exposed in `/metrics` |

## Folded in: CI fix for the failed `v0.7.0` tag

The `v0.7.0` tag failed in CI and Release (`make check` on a clean checkout). There is no separate
v0.7.1; the fix ships with this release.

- `make check` failed: `node tracker/build.mjs` could not import `esbuild` because nothing ran `npm ci`.
  The `tracker` target now depends on `tracker/node_modules` (locked `npm ci`); `tracker-test` no longer
  uses `npm install`.
- `release.yml` built the tracker without installing its dependencies: now `npm ci` first.
- `release.yml` used the retired `macos-13` runner for `x86_64-apple-darwin`: now `macos-15-intel`.
- Regression test `ci_regression_tracker_target_installs_locked_node_dependencies`.
- Verified by running `make check` from a clean `git ls-files` checkout (no `node_modules`, no `dist`).
