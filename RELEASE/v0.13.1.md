# RELEASE v0.13.1 — Patch: security advisories in the lockfile

**Status:** ready — `cargo audit` and `cargo deny` green locally; tag run pending (user)
**Theme:** the `v0.13.0` CI run failed in the Dependency-audit job (RUSTSEC-2026-0385).

## Release notes

### Fixed
- `ctutils` 0.4.3 → 0.4.5 clears **RUSTSEC-2026-0385** (non-constant-time mask generation and `u128`
  comparisons; patched in 0.4.4). Transitive via `digest 0.11` ← `sha1`/`sha2` ← sqlx-mysql.
- `tokio` 1.53.2 → 1.54.1 clears **RUSTSEC-2026-0386** (`AsyncFd` constructors violate I/O safety;
  patched in 1.53.3 — a warning-level unsound advisory, fixed in the same bump).

`cargo update -w` moves nothing else: every other crate is already at the highest version its
`Cargo.toml` requirement allows; the remaining majors (jsonwebtoken on 9.x, ADR 0052, axum 0.8,
sqlx 0.9) are pinned on purpose. No new dependencies, no `Cargo.toml` change.

## No AC changes

AC0.13.1–3 keep their tests; `make check`, `cargo audit` and `cargo deny check` green on the bumped
lockfile.
